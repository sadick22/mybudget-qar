# MyBudget QAR 💰

A comprehensive personal budgeting web app built for Sadick in Doha, Qatar.

## Features

- 📊 **Dashboard** — salary overview, credit card balance, spending summary
- 💳 **Credit Card Tracker** — balance vs limit, payoff simulator, fee history
- 💰 **Budget Planner** — category budgets, actual vs planned, charts
- 📝 **Transactions** — log income & expenses, search, filter, CSV export
- 📈 **Analytics** — monthly trends, category breakdown, fee cost tracker
- 🎯 **Goals** — debt payoff, savings goals, emergency fund tracker
- 🧮 **Calculators** — payoff, savings, interest cost, 50/30/20 rule
- ⚙️ **Settings** — profile, theme, data backup & restore

## Tech Stack

- React + Vite
- Recharts (charts)
- Lucide React (icons)
- localStorage (data persistence)
- No backend required

## Getting Started

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Push to GitHub
2. Import repo at vercel.com
3. Deploy — no config needed!
